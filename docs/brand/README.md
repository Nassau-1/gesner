# Gesner brand assets

Blue `#0A66C2`, ink `#202124`, white `#FFFFFF`.

- `logo-light.svg` / `logo-dark.svg`: horizontal logo, for light/dark backgrounds. Lettering is outlined; no font installation is needed.
- `wordmark.svg`: standalone outlined lettering.
- `mark-blue.svg`, `mark-black.svg`, `mark-white.svg`: standalone G.
- `icon.svg`: source for the square application icon.
- `logo-*.png`, `mark-blue.png`: transparent PNG exports.
- `social-1280x640.png`: GitHub social preview image.
- `store-small-440x280.png`: Chrome Web Store promotional image.
- `preview.png`: overview of the identity.

Chrome PNG icons are in [public/icons](../../public/icons). The 128px icon has 16px transparent padding on each side; toolbar icons use less padding for legibility. SVG files are the editable master assets. Keep their proportions and leave clear space around the logo.

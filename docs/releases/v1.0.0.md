# Gesner v1.0.0
Made by Enzo Terrier (Nassau-1).

A fully local spreadsheet workflow for web data: detect tables and lists, preview and clean columns, collect additional pages, and export Excel or CSV. No telemetry, accounts, API keys or cloud processing.

## Included
- Compact light workspace with all primary controls on screen.
- Table/list detection, column visibility and names, and row filtering.
- Bounded Next-button and infinite-scroll collection.
- Local CSV/XLSX/clipboard exports named YYYY.MM.DD_[page title].
- Source code, privacy documentation, synthetic screenshots and contributor guidance.

## Install
Download gesner-1.0.0.zip, extract it, and use Load unpacked in Chrome's extensions page with Developer mode enabled. Keep the extracted folder in place.
